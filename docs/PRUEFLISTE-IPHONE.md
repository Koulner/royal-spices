# Prüfliste iPhone: Royal-Spices-Vorschau

Für eine Person mit iPhone, ohne Vorwissen. Dauer etwa 15 Minuten. Bitte erst verschicken, wenn der Endstand auf der Vorschau liegt (Übertrag D gepusht).

**Adresse:** https://koulner.github.io/royal-spices/ (in **Safari** öffnen, nicht in einer anderen App)

**Gut zu wissen:** Das ist eine Vorschau. Das Anfrageformular verschickt hier nichts, und es gibt noch keinen Warenkorb.

## So meldest du ein Problem

Hake jeden Punkt ab: ✓ passt, ✗ passt nicht. Bei ✗ bitte:

1. ein Bildschirmfoto machen (Seitentaste und Lauter-Taste gleichzeitig drücken) oder bei Bewegung eine Bildschirmaufnahme,
2. in einem Satz notieren, was du getan hast und was passiert ist,
3. einmal angeben: iPhone-Modell und iOS-Version (Einstellungen → Allgemein → Info).

## Die Punkte

| Nr. | Was du tust | Was passieren soll | ✓ / ✗ |
|---|---|---|---|
| 1 | Startseite öffnen und kurz warten. | Nach wenigen Sekunden steht ein scharfes Safranglas da. Nichts bleibt leer oder grau. | |
| 2 | Auf der Startseite langsam nach unten wischen, dann schneller, dann wieder nach oben. | Das Bild bewegt sich mit dem Finger mit, ohne Ruckeln, Springen oder Flackern. Die Texte sind gut lesbar. | |
| 3 | iPhone ins Querformat drehen und zurück. | Nichts ist abgeschnitten. Die Seite lässt sich nicht seitlich verschieben. | |
| 4 | Oben rechts auf „Menü“ tippen, einen Punkt wählen, dann mit der Zurück-Geste (vom linken Rand wischen) zurück. | Das Menü öffnet und schließt sich. Die Seite wechselt, und zurück landest du wieder an der vorherigen Stelle. | |
| 5 | Auf der Startseite weiter unten (und auf „Für den Handel“) das Video antippen. | Das Video spielt im Bild, ohne Wartekreis. Am Ende erscheint „Noch einmal“, und das funktioniert. | |
| 6 | Über das Menü „Produkte“ öffnen, dann das Glas. | Fotos sind scharf. Ganz oben führt „Start“ zurück. Der Knopf „Glas anfragen“ öffnet das Formular. | |
| 7 | Im Formular (Seite „Kontakt“) ohne Eingabe auf „Anfrage senden“ tippen. | Rote Hinweise erscheinen an den Pflichtfeldern. | |
| 8 | Bei „Anliegen“ Catering wählen, dann in die Felder tippen: E-Mail, Telefon, Gästezahl, Wunschtermin. | Das Auswahlmenü öffnet sich. Die passende Tastatur erscheint (z. B. mit @ bei E-Mail). Beim Datum öffnet sich ein Kalender. Die Seite zoomt beim Tippen nicht von selbst heran. | |
| 9 | Unten auf der Seite die Telefonnummer und die E-Mail-Adresse antippen, dann **abbrechen**. | Telefon bzw. Mail-App bieten den Kontakt an. Bitte nicht wirklich anrufen oder schreiben. | |
| 10 | Stromsparmodus einschalten (Kontrollzentrum, Batteriesymbol), Startseite neu laden, Punkt 2 und 5 wiederholen. Danach wieder ausschalten. | Die Seite bleibt bedienbar. Wenn sich etwas nicht bewegt, steht trotzdem ein sauberes Bild da. | |
| 11 | In Safari unten auf „aA“ tippen und die Schrift größer stellen, eine Unterseite ansehen, wieder zurückstellen. | Texte werden größer und überlappen sich nicht. | |

## Zum Schluss

Dein Gesamteindruck in einem Satz: Wirkt die Seite hochwertig und fertig? Was ist dir als Erstes aufgefallen?
