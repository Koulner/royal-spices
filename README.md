# Royal Spices — The Journey of Saffron

Überarbeitete interaktive WebGL-Animation mit 800 permanenten, biegsamen Safranfäden. Alle 800 landen geprüft innerhalb der bestehenden gravierten Metallschale. Kein Verschieben, Löschen oder Ersetzen im Renderer.

Vorschau: http://127.0.0.1:4182/#scene-story

Die Website liegt in dist/ und benötigt einen HTTP-Server, keine Installation oder Kompilierung. Die Szene lädt erst nahe ihrem Seitenabschnitt. Die Kernelemente funktionieren ohne WebGL und ohne JavaScript.

Glasreferenz, hochauflösend neu gesetztes Etikett, Walnussholz, moderner rustikaler Küchenhintergrund und ruhige durchgehende Kamerareise sind integriert. Die Metallschale wurde einschließlich Geometrie, Gravurdatei und Material unverändert übernommen.

[Prüfprotokoll und Näherungen](PRUEFPROTOKOLL.md) · [Objektverfolgung](objektverfolgung.csv) · [Visuelle Zustände](qualitaet/desktop-uebersicht.png).

Die bewegte Szene ist eine Echtzeit-WebGL-Fassung. Ein vorgerenderter Film ist nicht enthalten. Die echte Domain royalspices.de wurde nicht geändert.
